# 🎓 AI Examiner: LLM-агент, що приймає іспит з NLP

**Запущений сервіс:** https://ВАШ-ЛІНК.streamlit.app  ← вставте після деплою
**Код:** https://github.com/ВАШ-АКАУНТ/ai-examiner

## Задача

Ми створили LLM-агента, який приймає усний іспит з курсу «Обробка природної мови». Агент:

1. дає студенту обрати рівень складності кнопками над чатом: початковий, середній або складний;
2. питає в студента ім'я та email і перевіряє його в базі (`start_exam`). Якщо студента немає, просить уточнити дані;
3. отримує 2–3 випадкові теми і по черзі обговорює їх у форматі діалогу (кілька запитань на тему, уточнення залежно від відповіді) на обраному рівні;
4. переходить до наступної теми, коли відповідь достатньо якісна, коли студент каже, що не знає, або коли рівень знань уже зрозумілий;
5. після кожної теми ставить оцінку 0–10 з коментарем (`grade_topic`);
6. наприкінці показує студенту підсумкову оцінку та відгук (що було добре, над чим попрацювати) і записує результат разом з повною історією чату (`end_exam`).

## Інструменти агента

| Інструмент | Що робить |
|---|---|
| `start_exam(email, name, level) -> list[str]` | Шукає студента в `data/students.json`, записує початок іспиту (разом з рівнем) у `results/exams.jsonl`, повертає 2–3 випадкові теми з `data/topics.json`. Якщо студента не знайдено, повертає помилку. Рівень береться з інтерфейсу автоматично, модель його не вигадує і не питає. |
| `get_next_topic() -> str` | Видає наступну тему. Разом з нею агент отримує рівень складності та приховані «орієнтири для екзаменатора» саме для цього рівня. Вони допомагають ставити запитання й оцінювати; студенту їх не показують. |
| `grade_topic(topic, score, comment)` | **Додатковий інструмент.** Фіксує оцінку за тему, щоб підсумкова оцінка була обґрунтованою (середнє за темами). |
| `end_exam(email, score, history)` | Записує результат у `results/results.jsonl` і повний протокол у `results/<email>_<час>.json`. `history` — список повідомлень `{"role": "system" \| "user" \| "tool_call", "content", "datetime"}`; репліки бота мають роль `system`, як у специфікації. |

### Рівні складності

| Рівень | Які запитання | Що означає 10/10 |
|---|---|---|
| 🟢 Початковий | базові означення та інтуїція, без формул | правильно пояснює суть своїми словами з прикладом |
| 🟡 Середній | механізми, основні формули, порівняння підходів | пояснює механізм і порівнює підходи |
| 🔴 Складний | обґрунтування, компроміси, сучасні методи, «а чому?» | аналізує компроміси і відповідає на поглиблені запитання |

Як рівень утримується протягом усього іспиту:
- рівень обирається в інтерфейсі **до старту** і після першого виклику `start_exam` блокується, тож змінити його посеред іспиту не можна;
- обраний рівень підставляється в системний промпт ще до старту (і оновлюється, якщо студент перемкнув кнопку), тому модель знає його з першого повідомлення і **не перепитує** студента;
- для кожної теми в `data/topics.json` є окремі орієнтири для кожного рівня (`levels.basic / intermediate / advanced`);
- рівень передається моделі в результатах `start_exam` і **повторно в кожному `get_next_topic`**, тому модель не «забуває» його в довгому діалозі;
- системний промпт забороняє змінювати складність посеред іспиту, навіть на прохання студента;
- оцінка ставиться відносно очікувань обраного рівня, а сам рівень записується в результати (`results.jsonl`) поруч з оцінкою.

### Захисні механізми
- **Перевірки в коді, а не лише в промпті:** не можна взяти нову тему, не оцінивши поточну; не можна завершити іспит, поки не всі теми оцінено; не можна почати іспит двічі.
- **Порядок завершення:** `end_exam` фактично записує результат наприкінці ходу, *після* того як студент побачив відгук, тож у `history` потрапляє і фінальне повідомлення.
- **Prompt injection:** системний промпт забороняє змінювати оцінку на прохання студента та розкривати орієнтири.
- **Стійкість до збоїв API:** автоматичні повтори запитів; якщо модель перевантажена або недоступна (503, 429, 404), агент сам переходить на запасну модель того ж провайдера і показує про це примітку в чаті. Якщо не відповіла жодна модель, стан діалогу відкочується і студент просто надсилає відповідь ще раз.
- **Кілька користувачів одночасно:** стан іспиту зберігається окремо для кожної сесії браузера.

## Архітектура

```
streamlit_app.py   вебінтерфейс (Streamlit): чат, поле для API-ключа, журнал результатів
agent.py           цикл агента: LLM ↔ tool calling, опис інструментів (JSON-схеми)
tools.py           python-функції start_exam / get_next_topic / end_exam, стан сесії
prompts.py         системний промпт екзаменатора + розділ про обраний рівень (build_system_prompt)
data/              students.json, topics.json (15 тем, для кожної орієнтири на 3 рівні)
tests/             6 тестів з фейковою LLM: повний іспит, рівні, відкат при помилці, запасні моделі
```

Агент працює з будь-яким OpenAI-сумісним API. У бічній панелі можна обрати провайдера:

| Провайдер | Ключ | Моделі за замовчуванням |
|---|---|---|
| Google Gemini | безплатний: https://aistudio.google.com/apikey | `gemini-flash-latest`, `gemini-flash-lite-latest` |
| Groq | безплатний: https://console.groq.com/keys | `openai/gpt-oss-120b`, `qwen/qwen3.6-27b`, `openai/gpt-oss-20b` |
| xAI Grok | платний: https://console.x.ai | `grok-4.7`, `grok-4-1-fast-non-reasoning` |

Назву моделі можна вписати вручну. Провайдера можна змінити навіть посеред іспиту, бо історія діалогу зберігається у форматі, сумісному з усіма трьома API.

## Як користуватися

1. Отримайте ключ (найпростіше безплатний ключ Gemini або Groq, посилання вище).
2. Відкрийте сервіс, оберіть провайдера і вставте ключ у бічній панелі (ключ ніде не зберігається).
3. Над чатом оберіть рівень складності.
4. Напишіть ім'я та email одного з тестових студентів (список є в бічній панелі), наприклад `Test Student, test@example.com`.
5. Відповідайте на запитання. Перемикач «Показувати виклики інструментів» дозволяє бачити, які функції викликає агент.

## Локальний запуск

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
python -m pytest tests -q      # тести (не потребують API-ключа)
```

## Розподіл роботи

- **Ім'я 1:** функції-інструменти та дані (`tools.py`, `data/`), цикл агента (`agent.py`), тести.
- **Ім'я 2:** системний промпт (`prompts.py`), вебінтерфейс (`streamlit_app.py`), тестування сценаріїв, деплой, звіт.

## Особливості

- Безплатні моделі іноді перевантажені ввечері. Якщо в чаті часто з'являється примітка «модель недоступна», оберіть у бічній панелі запасну модель (наприклад, `gemini-flash-lite-latest`) або іншого провайдера.
- На безплатному Streamlit Community Cloud диск не постійний: після перезапуску застосунку журнал результатів очищується. Для демонстрації цього достатньо; для реального використання результати варто писати в базу даних.
- Застосунок «засинає» після кількох годин без відвідувачів; перше відкриття після цього займає до хвилини.
